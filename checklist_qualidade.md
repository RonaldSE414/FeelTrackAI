# ✅ Checklist de Inspeção de Qualidade

## 1. Cadastro de Usuário

* [x] Validação dos campos obrigatórios (nome, e-mail e senha).
* [x] Bloqueio de cadastro quando houver campos vazios.

## 2. Autenticação (Login)

* [x] Validação das credenciais por meio do banco de dados.
* [x] Permissão de acesso apenas para usuários cadastrados.

## 3. Persistência dos Dados

* [x] Verificação do sucesso das operações de cadastro.
* [x] Cancelamento da operação em caso de erro de conexão ou inserção de dados.

## 4. Questionário Emocional

* [x] Controle dos valores por meio de componentes JSlider.
* [x] Restrição dos valores entre 0 e 10.

## 5. Cálculo do Estado Emocional

* [x] Processamento automático das respostas do questionário.
* [x] Determinação automática do estado emocional do usuário.

## 6. Classificação Emocional

* [x] Classificação dos resultados em Saudável, Moderado ou Crítico.
* [x] Geração de recomendações adequadas para cada classificação.

## 7. Assistente IA

* [x] Identificação de palavras-chave relacionadas ao contexto emocional.
* [x] Geração de mensagens de apoio personalizadas.

## 8. Controle de Sessão

* [x] Armazenamento do ID do usuário autenticado.
* [x] Armazenamento do nome do usuário durante a navegação no sistema.

## 9. Restrições da Interface

* [x] Bloqueio de valores inválidos nos controles do questionário.
* [x] Bloqueio de cadastro com campos obrigatórios vazios.
* [x] Restrição de acesso às funcionalidades mediante autenticação.

* [x] Validação de login.

* [x] Cálculo automático do estado emocional.
